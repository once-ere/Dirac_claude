## 3. Why the notebook Lagrangian Lg[] cannot be used for a Grassmann field

Notebook `Lg[] = √g [Ψ^T σ16 Σ_α T16^α (∂_α Ψ + (Q1/2) Σ_ab ωmat[α,a,b] SAB[a,b] Ψ) + H M Ψ^T σ16 Ψ]`
(Q1 = 1 book-keeping switch; notebook treats f16[k] as commuting functions).

1. For Grassmann-odd `Ψ` and ANY matrix `M`: `Ψ^T M Ψ = Ψ^T M_antisym Ψ`.
   `σ16` is symmetric => mass term `Ψ^T σ16 Ψ ≡ 0`.
2. `σ16 γ^a` antisymmetric => `Ψ^T σ16 γ^μ ∂_μ Ψ = (1/2)∂_μ(Ψ^T σ16 γ^μ Ψ)
   - (1/2) Ψ^T (∂_μ σ16 γ^μ) Ψ`: a total derivative plus a derivative-free term.
3. `σ16 γ^c Ω_c`: only `C[γ^c,S^{ab}]/2` (vector/trace part) survives for Grassmann
   fields; with `√g`, it cancels exactly against item 2's derivative-free term by the
   divergence identity `∂_μ(√g γ^μ) = √g [γ^μ, Ω_μ]` (§5).  Net: for a real
   Grassmann Ψ16, `√g Lg[]` is a pure divergence — the Euler–Lagrange equations are
   empty (0 = 0).  This must be demonstrated (proof + explicit Grassmann-algebra check
   in Python on a random constant-coefficient example + symbolic check).
4. Index placement: `ωmat[[μ,a,b]] = e^a_k ∇_μ e_b^k = ω_μ^a_b` (mixed).  Lg[]
   contracts it with `SAB[[a,b]] = S^{ab}` (both upper) — one η is missing.
   [VERIFIED] in the primordial field, `D_μ γ^ν = 0` FAILS with the notebook contraction
   and HOLDS with `Ω_μ = (1/2) ω_{μab} S^{ab}`, `ω_{μab} = η_ac ω_μ^c_b`.  For a
   mixed space/time frame pair, `ω_μ^a_b` is symmetric in (a,b), so the notebook
   contraction silently deletes every boost-type component.
5. For COMMUTING Ψ (the notebook's actual use) the symmetric part picks
   `C{γ^c,S^{ab}}` = the totally antisymmetric part `ω_[cab]`, which vanishes for
   diagonal metrics; the gravitational term in the notebook's EL equations then
   comes from `∂_μ(√g γ^μ)`, not from the spin connection.
