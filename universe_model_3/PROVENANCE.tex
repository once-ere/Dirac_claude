\section{The fold: definition and
examples}\label{the-fold-definition-and-examples}}

\textbf{Definition.} The \emph{fold} is the seven-dimensional surface of
the author's eight-dimensional spacetime on which the cosine of the
angle \(z = 6Hx_0\) of the hidden direction vanishes:

\[
\mathcal{F} = \big\{X = (x_0, x_1, \dots, x_7):\ \cos(6Hx_0) = 0\big\},\qquad
\text{in one period } 0 < z < \pi\text{ of the metric: } z = \frac{\pi}{2},\quad x_0 = \frac{\pi}{12H} \tag{FD-1}
\] \textbf{Symbols in (FD-1).}

\begin{itemize}

  where \(\sigma = 0\); \(\vert_{\mathcal{F}}\) means restricted to the
  fold. Status: DERIVED.
\item
  \(X = \{x_0, \dots, x_7\}\): The author's coordinates of the

  hidden direction first (Dirac\_Einstein-Lovelock\_4+4\_Nash.nb,

  \(\mathrm{d}^8X = \mathrm{d}x_0\,\mathrm{d}x_1\cdots\mathrm{d}x_7\)
  the coordinate volume element. Unit: length (each coordinate). Status:
  AUTHOR.

  \(\pi/(6H)\). Unit: length. Status: AUTHOR.

Every script prints one line per check and ends with ``n/n checks
passed''; \texttt{um3\_series.py}, \texttt{um3\_background.py} and
\texttt{um3\_foldsources.py} read the outputs of \texttt{um3\_fold.py}
(and \texttt{um3\_background.py} and \texttt{um3\_primordial.py} that of
\texttt{um3\_geometry.py}), \texttt{um3\_bulk.py} reads the report of
\texttt{um3\_weights.py}, \texttt{um3\_primordial.py} the outputs of
\texttt{um3\_background.py} and \texttt{um3\_superluminal.py},
\texttt{um3\_krein.py} reads the snapshots of the parts of
\texttt{um3\_kohnsham.py}, \texttt{um3\_linear.py} reads nothing, and
\texttt{um3\_cosmology.py} downloads the Planck files once (about 7 MB).
By the standing rule no single calculation may take longer than 423
seconds: each command is run under \texttt{timeout\ 423}; a part of
\texttt{um3\_kohnsham.py} that reaches its own limit of 400 seconds
saves its state and exits with the code 3, and is then simply run again
until it exits with 0 (the six parts together take about 37 minutes of
computing; the longest single module otherwise is
\texttt{um3\_krein.py}, about 4.5 minutes). The documents are rebuilt
identically (no dates in the LaTeX, fixed PDF metadata).
