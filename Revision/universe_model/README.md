# Revision/universe_model — UM-1, a 4+4 model of the Universe (order of 2026-10-17)

| file | content |
| --- | --- |
| `MODEL.md`, `MODEL.pdf` | the model: fields, action, the power-series metric, the $x_0$ mass mechanism, the portal interactions, assumptions |
| `PROVENANCE.md`, `PROVENANCE.pdf` | the origin of every ingredient (record, standard physics, new) |
| `FIELD_EQUATIONS.md`, `FIELD_EQUATIONS.pdf` | the coupled field equations, derived by `field_equations/derive_field_equations.py` |
| `SOLUTION.md`, `SOLUTION.pdf` | an approximate solution, computed by `solution/solve_model.py` |
| `tools/md2tex.py`, `tools/build_pdfs.sh` | Markdown → LaTeX → PDF (the .md files are the sources) |

Build the PDFs from the repository root: `bash Revision/universe_model/tools/build_pdfs.sh`.
